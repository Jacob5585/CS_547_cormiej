****************************************
APPROACHES: 
****************************************

* base_model
	 Base 3 layer CNN with a 4th layer fully connected layer.

* base_model_augmentations
	 Base 3 layer CNN with a 4th layer fully connected layer, uses data aguemtnations for random horizontal flips and rotations to the.

* lightweight_gap_model
	 Lightweight CNN using batch normalization, leaky ReLU, and global average pooling instead of fully connected layers.

* avgpool_batchnorm_model
	 CNN with batch normalization and adaptive average pooling replacing max pooling.

* multiscale_kernel_model
	 CNN with progressively smaller kernel sizes (7 -> 5 -> 3) and batch normalization.

* multiscale_kernel_augmented
	 CNN with progressively smaller kernel sizes (7 -> 5 ->3) and batch normalization, uses data augmentation such as flips, rotations, and color jitter

* deep_block_model
	 Deeper CNN with stacked convolutional blocks, batch normalization, and dropout.

* deep_block_augmented
	 Deeper CNN with stacked convolutional blocks, batch normalization, and dropout, uses data augmentation for random horizontal flips, rotations, and normalization.

  (5): MaxPool2d(kernel_size=2, stride=2, padding=0, dilation=1, ceil_mode=False)
